# Локальные тестовые данные

Синтетические изображения создаются локально:

```bash
python examples/generate_test_images.py --output-dir data/synthetic --size 512
```

Внешние архивы сохраняйте в `data/external/`. Они не входят в Git, поскольку могут быть большими и иметь отдельные условия лицензирования.

Перед запуском пакетного эксперимента заполните копию `manifest.example.csv` и проверьте права на использование изображений. Подробные сведения об источниках и ограничениях приведены в [руководстве по наборам тестовых изображений](../docs/test-image-sources.md).
