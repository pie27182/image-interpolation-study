# Аудит зависимостей самостоятельной реализации

## Вычислительное ядро scratch

Модули `src/interpolation_study/resize.py` и `kernels.py` содержат алгоритмы передискретизации и реконструкционные ядра. Они используют:

- **NumPy** — массивы, индексацию и численные операции;
- **стандартную библиотеку Python** — типы и служебные структуры.

Они не импортируют и не вызывают Pillow, OpenCV, SciPy, scikit-image, PyTorch, TensorFlow или другие готовые реализации изменения размера изображений. Модуль `metrics.py` также реализует MSE, PSNR и используемый вариант SSIM на NumPy.

В `resize.py` Pillow не используется даже косвенно через API изменения размера: вычисления выполняются собственным кодом проекта. Автоматический тест проверяет импорты ключевых модулей, чтобы случайная зависимость не появилась незаметно.

## Зачем проекту нужна Pillow

Pillow применяется вне вычислительного ядра:

- чтение и сохранение распространённых форматов файлов изображений в CLI;
- отдельная библиотечная базовая реализация для сравнительных экспериментов.

Поэтому полное приложение зависит от Pillow, но функция `interpolation_study.resize.resize` может быть вызвана непосредственно с массивом NumPy без Pillow. Для воспроизводимого сравнения Pillow оставлена явной альтернативой, а не подменяет алгоритмы scratch.

## Matplotlib

Matplotlib — необязательная зависимость только для построения графиков. Он не участвует в интерполяции, метриках или измерении времени. Установка:

```bash
python -m pip install -e '.[plots]'
```

## Быстрая проверка вручную

```bash
python -c "import sys; import interpolation_study; print(interpolation_study.resize)"
```

Для CLI и сравнительного benchmark используется Pillow для файлового ввода-вывода и эталонной реализации. Вычислительное ядро scratch остаётся независимым от библиотек интерполяции.
