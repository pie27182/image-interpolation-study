# Протокол экспериментов

Этот протокол задаёт минимальную схему сравнения. Конкретный объём данных и статистический анализ следует согласовать с требованиями дипломной работы.

## 1. Набор изображений

Используйте разнообразные изображения с разрешёнными для исследования лицензиями: фотографии, портреты, мелкие текстуры, текст и тонкие линии, схемы, пиксельную графику или маски. Практический ориентир — 15–30 фотографий/текстур плюс отдельные синтетические паттерны. Не смешивайте сводные метрики синтетических изображений и фотографий без явного разделения по классам.

Для проверки отдельных свойств дополните набор синтетическими примерами:

```bash
python examples/generate_test_images.py --output-dir data/synthetic --size 512
```

Скрипт создаёт восемь детерминированных изображений: градиент, контрастные границы, импульс, наклонную границу, периодическую решётку, Zone Plate, звезду Siemens и частотный sweep. Вызов с явным каталогом вывода: `python examples/generate_test_images.py --output-dir data/synthetic --size 512`. Для каждого внешнего исходного изображения запишите источник, лицензию и размеры. Проверенные внешние наборы и правовые ограничения описаны в [руководстве по наборам тестовых изображений](test-image-sources.md).

## 2. Коэффициенты масштабирования

Проверьте увеличение в 2, 3 и 4 раза и уменьшение до 0.75, 0.5 и 0.25 исходного размера. Сравнивайте методы только при одинаковых размерах входа и выхода. Увеличение и уменьшение анализируйте отдельно.

## 3. Контролируемое сравнение

Для эксперимента с эталонным изображением высокого разрешения создайте вход низкого разрешения с помощью документированного фильтра, а затем восстановите исходные размеры. Все методы должны получать один и тот же массив низкого разрешения.

Повторите эксперимент с несколькими способами уменьшения (например, area, bilinear, bicubic и Lanczos). Иначе метод, совпадающий с фильтром создания тестовых данных, может получить необоснованное преимущество. Параметры самостоятельной реализации и различия с Pillow описаны в [заметках об алгоритмах](algorithm-notes.md).

## 4. Оценка качества

Приводите MSE, PSNR и используемый в проекте вариант SSIM с равномерным окном. Для SSIM укажите размер окна (по умолчанию 7×7), диапазон данных (255 для 8-битных изображений или 1 для данных [0,1]) и вариант обработки каналов.

Числа дополняйте визуальным сравнением увеличенных фрагментов. Обсудите резкость границ, размытие, звон/ореолы, ступенчатость, муар и сохранение текстур: одни метрики не описывают воспринимаемое качество полностью.

## 5. Время выполнения

Выполняйте прогрев и не менее 5–10 измеряемых повторов для итоговых результатов. Сообщайте медиану и разброс (например, стандартное отклонение или межквартильный размах). Замеряйте передискретизацию отдельно от загрузки, сохранения и вычисления метрик. Запишите характеристики компьютера и версии Python, NumPy и Pillow.

## 6. Что фиксировать в отчёте

Для каждого запуска сохраните:

- идентификатор изображения, источник и лицензию;
- размеры исходного/целевого изображений и коэффициент масштабирования;
- метод и параметры фильтра ухудшения и реконструкции;
- режим координат, границ и подавления наложения спектров;
- обработку цветового пространства, каналов и альфа-канала;
- диапазон данных и настройки метрик;
- количество прогревов/повторов и статистику времени;
- версии программного обеспечения и сведения об оборудовании.

В выводах разделяйте визуальное качество, значения метрик и скорость. Не объявляйте универсально лучший метод по одному изображению или одному фильтру ухудшения.
